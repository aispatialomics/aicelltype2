# aicelltype2
> A curated collection of AI foundation models, large language models (LLMs), and multimodal methods for cell type annotation, discovery, and analysis in single-cell and spatial omics.

## 📖 Overview

AI-CellTypes is an open-source repository that summarizes AI-driven methods for **cell type identification** across single-cell and spatial omics.

This repository aims to provide researchers with:

- 📚 A curated list of recent AI models
- 🧬 Cell type annotation methods
- 🔬 Spatial transcriptomics foundation models
- 🤖 Large language model (LLM) applications
- 🖼️ Vision-language and multimodal approaches
- 📄 Papers, code, datasets, and benchmarks
